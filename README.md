# CampusMate — Smart Campus Management Platform

One Smart Platform for a Better Campus — combining FIXORA (maintenance), 
CLEANWISE (cleanliness) and HOSTELHUB (hostel parcel management).

## Project Status — Phase 1 (35% Completion)

**Completed:**
- Responsive UI/UX for landing page, FIXORA, CLEANWISE and HOSTELHUB sections
- Report submission form with photo upload field
- Student dashboard layout with search/filter
- Sample dashboard view (AI Priority Insight, stats, recent activity table)

> Note: Dashboard numbers, AI Priority Insight text, and parcel status shown 
> in this version are placeholder/sample data for UI demonstration purposes.

**Planned for Phase 2:**
- Backend (Node.js + Express) and MongoDB integration
- Real authentication (student/admin roles)
- Real AI-based complaint categorization, severity detection and duplicate grouping
- Image upload storage (Cloudinary/S3)
- Real-time status updates (Socket.IO)
- OTP-based parcel pickup workflow
- Notification system
